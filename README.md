# MyFitPal UK - Final GitHub Pages Build

Unified search box:
- Type product name: "Asda skimmed milk", "Tesco chicken", "Oatly"
- Type barcode number: 5000157023425 etc
- Or tap camera icon to scan barcode

Linked to:
- UK search: https://uk.openfoodfacts.org/cgi/search.pl?search_terms=...&json=true&page_size=20
- UK product: https://uk.openfoodfacts.org/api/v0/product/{barcode}.json
- Fallback: world.openfoodfacts.org
- Offline: 85+ CoFID-style foods built-in

Deploy:
1. Create repo myfitpal
2. Upload all files from this folder to repo root
3. Settings > Pages > Deploy from branch > main / root
4. Live at https://YOURNAME.github.io/myfitpal/

Add to Home Screen on phone for native app feel.
